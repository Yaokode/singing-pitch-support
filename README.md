# app

ここに、音程練習支援ツールの静的Webアプリを作る。

## 初期MVP

- `index.html`: 画面
- `styles.css`: 見た目
- `main.js`: マイク入力と音程判定

## 守ること

- 録音データを保存しない
- 児童名を入力しない
- 点数や順位を表示しない
- 外部サーバーへ音声を送らない

## 起動方法

`app/` をローカル配信して開く。

```bash
python3 -m http.server 4173 --directory app
```

ブラウザで次を開く。

```text
http://127.0.0.1:4173/index.html
```

## 初期確認

1. 「目標音」を押して音が鳴るか確認する
2. 必要に応じて「ガイド音量」を調整する
3. 「マイク開始」を押してブラウザのマイク許可を出す
4. 反応しにくい時は「マイク感度」を高める
5. 小さい声、ハミング、「ルー」で反応を見る
6. 判定がぶれる場所や端末を記録する
7. 児童に使う前に、教師端末で必ず試す

## フレーズ練習

「曲プリセット」を選ぶと、確認用の音列とテンポが入る。
「音列」に直接入力しても、テンポに合わせて目標音が進む。

```text
ド4:1 レ4:1 ミ4:1 ソ4:1 ミ4:1 レ4:1 ド4:2
```

- `ド4:1`: 1拍
- `ド4:1.5`: 1.5拍
- `ド4:2`: 2拍
- `休:1`: 1拍休み
- `ガイド音`: 目標音を鳴らすかどうか
- `ガイド音量`: 目標音の大きさ。小さめ、ふつう、大きめから選ぶ
- `本体音対策`: スピーカーから出るガイド音をマイクが拾いにくくする設定
- `マイク感度`: 声を拾いにくい時の端末内調整
- `歌う高さ`: 教師の低い声で試す時は1オクターブ下にできる
- `オクターブ補正`: 倍音で1オクターブずれて見える時の補正

画面には音階メーターがあり、「目標」と「今の声」の位置でずれを見られる。
フレーズを通して確認すると、各音の下に `近` `低` `高` の記録がその場だけ残る。
楽譜風プレビューでは、黒丸が目標音、濃い丸が実際に拾った声の高さとして重ねて表示される。

曲プリセットのデータは確認用のたたき台。実際に使う前に、手元の楽譜で高さと長さを確認する。
コピペ用データは `docs/song-presets.md` にまとめている。

## 注意

- `file://` で直接開くと、ブラウザによってはマイクが使えない
- 学校端末では管理設定でマイクが制限されることがある
- 判定は練習の目安であり、評価や点数化には使わない
- 低い男性声で動作確認する時は、`歌う高さ` を `1オクターブ下` にすると試しやすい
- ガイド音をスピーカーから鳴らすと、マイクがその音を拾うことがある
- `本体音対策` はブラウザのエコーキャンセル等を使う軽減策で、完全に消せるとは限らない
- `本体音対策` を使うと、端末によっては音程検出が少し不安定になることがある
- マイク感度を上げすぎると、周囲の音やガイド音も拾いやすくなる
- 本当に1オクターブ違って歌っているか確認したい時は、「オクターブ補正」を「使わない」にする

## Chromebookで使う場合

児童端末に配る場合は、`app/` の3ファイルをHTTPSの静的Webサイトとして公開する。
Google Driveのファイル共有だけでは、マイク許可が安定しないことがある。

手順は `docs/chromebook-webapp-deploy.md` にまとめている。
